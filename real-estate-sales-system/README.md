# 不動産販売管理システム

不動産販売業向けの社内管理Webアプリです。**物件管理** / **顧客・商談** / **営業・内見** を1画面で管理できます。

サーバーやビルドは不要で、ブラウザだけで動作します。データは各ブラウザの `localStorage` に保存されます（オフライン利用可能）。

## 使い方

```
real-estate-sales-system/index.html をブラウザで開くだけです。
```

ローカルサーバーで開きたい場合:

```bash
cd real-estate-sales-system
python3 -m http.server 8080
# → http://localhost:8080 をブラウザで開く
```

## 機能

### ダッシュボード
- KPIカード（販売中物件数・販売総額、進行中商談・見込金額、成約済物件数、今後の内見件数）
- 販売中の物件一覧
- 進行中の商談一覧
- 今後の内見予定

### 物件管理
- 物件（物件番号／物件名／種別／所在地／販売価格／間取り／面積／担当営業）の登録・編集・削除
- **物件写真の添付**（登録・編集画面で画像を選択。800px以内へ自動縮小して保存し、一覧にサムネイル表示）
- 種別: マンション / 戸建 / 土地 / 収益物件
- ステータス: 公開前 / 販売中 / 商談中 / 成約済（絞り込み対応）
- ㎡単価を自動計算、物件名・住所・物件番号での検索
- **CSV出力**（物件一覧をExcel対応のCSVで書き出し）

### 顧客・商談管理
- 顧客（顧客名／電話／メール／ご予算／希望条件）の管理
- 商談（商談名／顧客／対象物件／担当営業／想定成約価格／ステージ／次アクション日／成約日）の管理
- 商談ステージ: 問合せ → 内見 → 申込 → 契約 → 成約 / 見送り
- ステージを「成約」にすると成約日が自動補完され、レポートの実績に集計されます
- 顧客を削除すると紐づく商談・内見も自動削除
- **CSV出力**（顧客一覧・商談一覧をそれぞれ書き出し）

### 販売レポート
- KPIカード（累計成約件数・累計成約金額、今月の成約、平均成約単価）
- **月次成約実績グラフ**（直近6ヶ月の成約金額を棒グラフで表示。各月の成約件数も併記）
- **担当者別 成約金額グラフ**（横棒グラフ）と売上集計表（担当物件数・成約件数・成約金額）
- **CSV出力**（担当者別売上をCSVで書き出し）

### 営業・内見管理
- 営業担当（社員番号／氏名／店舗／役職）の管理と担当物件数の表示
- 内見予約（日付／時刻／物件／顧客／担当）の登録・編集・削除
- 日付での絞り込み、過去日は「実施済」として自動表示

### データ入出力
- 画面右上の **エクスポート** で全データをJSONファイルに書き出し
- **インポート** でJSONファイルからデータを復元（バックアップ・端末間移行に利用）

## 技術構成

- 依存ライブラリなしの Vanilla JavaScript / HTML / CSS
- 永続化: ブラウザの `localStorage`（キー: `re_sales_mgmt_v1`）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面レイアウト |
| `style.css` | スタイル |
| `app.js` | ロジック・データ管理 |

## 注意事項

- データはアプリを開いたブラウザ内にのみ保存されます。別端末・別ブラウザとは共有されません。共有が必要な場合はエクスポート/インポートをご利用ください。
- 初回起動時はサンプルデータ（物件・顧客・商談・営業担当）が投入されます。
