# キーエンス管理システム

センサ・測定器などの製品を扱う事業向けの社内管理Webアプリです。**在庫・製品** / **顧客・案件** / **従業員・勤怠** の3業務を1画面で管理できます。

サーバーやビルドは不要で、ブラウザだけで動作します。データは各ブラウザの `localStorage` に保存されます（オフラインで利用可能）。

## 使い方

```
keyence-management-system/index.html をブラウザで開くだけです。
```

ローカルサーバーで開きたい場合:

```bash
cd keyence-management-system
python3 -m http.server 8080
# → http://localhost:8080 をブラウザで開く
```

## 機能

### ダッシュボード
- KPIカード（登録製品数・在庫金額、在庫アラート件数、進行中案件と見込金額、本日勤務中人数）
- 発注点を下回った製品の一覧
- 進行中案件の一覧
- 本日の勤怠状況

### 在庫・製品管理
- 製品（型番／製品名／カテゴリ／在庫数／発注点／単価）の追加・編集・削除
- ワンクリックの **入庫 / 出庫** 操作
- 在庫状態の自動判定（適正 / 要発注 / 欠品）と在庫金額の自動計算
- 型番・製品名での検索

### 顧客・案件管理
- 顧客（顧客名／担当者／電話／メール）の管理
- 案件（案件名／顧客／金額／ステータス／次アクション日）の管理
- ステータス: リード → 商談中 → 見積提出 → 受注 / 失注
- 顧客を削除すると紐づく案件も自動削除

### 従業員・勤怠管理
- 従業員（社員番号／氏名／部署／役職）の管理
- ワンクリックの **出勤 / 退勤 打刻**（実働時間を自動計算）
- 日付で勤怠記録を絞り込み、記録の手動編集も可能

### データ入出力
- 画面右上の **エクスポート** で全データをJSONファイルに書き出し
- **インポート** でJSONファイルからデータを復元（バックアップ・端末間移行に利用）

## 技術構成

- 依存ライブラリなしの Vanilla JavaScript / HTML / CSS
- 永続化: ブラウザの `localStorage`（キー: `keyence_mgmt_v1`）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面レイアウト |
| `style.css` | スタイル |
| `app.js` | ロジック・データ管理 |

## 注意事項

- データはアプリを開いたブラウザ内にのみ保存されます。別端末・別ブラウザと共有されません。共有が必要な場合はエクスポート/インポートをご利用ください。
- 初回起動時はサンプルデータが投入されます。
